# Examples

Self-contained scripts that demonstrate the LipMamba pipeline end-to-end on
toy data so they can run on a laptop CPU in a few seconds.

| Script | What it shows |
| --- | --- |
| `train_demo.py`           | Tiny training loop with PAC-Bayes objective |
| `certify_demo.py`         | Per-input certified radius + immunity bound |
| `attack_defense_demo.py`  | Run HiSPA against a randomly-initialised model |
| `ids_demo.py`             | LipMamba on a synthetic IDS-style flow tensor |
